# MechLab Web Operations

Operational documentation for deployment, rollback, release delivery, incident handling, environment configuration, and observability belongs here.

Required canonical runbooks during the architecture migration:

- deployment and preview environments;
- production cutover and rollback;
- Cloudflare Worker/R2 configuration;
- Supabase environment and auth configuration;
- release publishing and immutable artifact verification;
- incident response and diagnostics.

Operational facts must not live only in chat history, personal notes, or CI YAML comments.
